# Paint App

## Current features

- Drawing lines
- Changing the brush colour
- Change brush size
- Change brush type e.g. pen, pencil, spray-can
- Shapes, like circles and rectagles
- Fill or paint bucket tool that fills in a closed off space with a colour
- Undo and redo
- Save image as png or webp
- Save colours
